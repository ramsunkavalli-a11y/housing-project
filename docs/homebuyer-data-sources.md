# Free-source catalog for the homebuyer inventory

Desk review dated **2026-09-27**. This catalog checks source documentation and advertised access; it is **not** a completed download, current-release audit, coverage benchmark, or production license review. Earlier neighborhood extracts are documented separately. A listed API may require registration or impose limits. “National” describes intended scope, not complete records everywhere.

See the [inventory](homebuyer-data-inventory.md) for buyer-facing uses and the [review](homebuyer-data-review.md) for processing recommendations. Source IDs are stable within these planning documents.

## Important implementation findings from this sweep

- **SLD identifier trap:** its technical guide describes `GEOID20` as updated 2019 identifiers, alongside `GEOID10`. Do not infer a 2020 geography from the column name. Crosswalk or recompute after checking the actual boundary version. [SLD technical guide](https://www.epa.gov/system/files/documents/2023-10/epa_sld_3.0_technicaldocumentationuserguide_may2021_0.pdf).
- **Overture schema drift:** September 2026 Places documentation describes `taxonomy` and `basic_category`; older examples using `categories` can fail. Preserve source release and schema version. `confidence` concerns existence and is not strictly calibrated across providers; it does not establish quality or operating hours. [Places guide](https://docs.overturemaps.org/guides/places/).
- **Source publication is not collection time:** a fresh package may contain older records. Retain both release date and observation period.
- **Broadband access terms differ:** the FCC's [Fabric FAQ](https://help.bdc.fcc.gov/hc/en-us/articles/7412732399003-Fabric-FAQs) describes a separate licensing agreement for the full location dataset. Public availability data and a freely redistributable address database are different things.
- **Free download is not the whole cost:** storage, routing, updates, validation, and service operation require resources. No hosting/API subscription has been selected.

## Required checks before an actual collection batch

For each selected source: download a small sample; confirm fields and units; pin a release; verify supported geography and dates; check null/suppression conventions; document public-display and agent-response rights; inspect urban and less-dense examples; estimate refresh effort. Missing or unacceptable sources remain optional instead of blocking the entire product.

The goal is a useful broad dataset with visible gaps, not a claim that every cell can be filled for every location.
